1. 수집하는 개인정보 항목

rhwp Studio는 서비스 제공을 위해 다음과 같은 정보에 접근합니다:

항목목적보관 기간
Google 계정 정보 (이메일, 이름)사용자 식별세션 종료 시 삭제
Google Drive 파일 (drive.file 범위)HWP/HWPX 파일 열기 및 편집서버에 저장하지 않음

2. 개인정보의 이용 목적

  • Google Drive의 HWP/HWPX 파일 읽기 및 편집 기능 제공
  • 사용자 인증 및 Drive API 접근 권한 관리

3. 제3자 제공

수집된 개인정보는 서비스 제공 이외의 목적으로 제3자에게 제공되지 않습니다.

4. Google API 서비스 사용

본 서비스는 Google API 서비스를 사용하며, Google의 개인정보처리방침 및 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 데이터 보안

본 서비스는 사용자 파일 데이터를 서버에 저장하지 않습니다. 모든 파일 처리는 사용자의 브라우저 메모리에서만 이루어집니다.

6. 사용자 권리

사용자는 언제든지 Google 계정 설정에서 rhwp Studio의 Drive 접근 권한을 철회할 수 있습니다.
